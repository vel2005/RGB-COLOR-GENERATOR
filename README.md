RGB Color Generator

A simple and interactive RGB Color Generator built using HTML, CSS, and JavaScript. This project allows users to adjust Red, Green, and Blue color values using sliders and instantly preview the generated color along with its RGB code.

🚀 Features
Generate colors using RGB values (0–255)
Real-time color preview
Interactive sliders for Red, Green, and Blue channels
Displays the current RGB color code
Clean and responsive user interface
Beginner-friendly JavaScript project
🛠️ Technologies Used
HTML5
CSS3
JavaScript (ES6)
📸 How It Works
Move the Red, Green, and Blue sliders.
The background color updates instantly.
The corresponding RGB value is displayed.
Use the generated RGB code in your web projects.
